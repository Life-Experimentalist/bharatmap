Correct India map borders for web maps

bharatmap makes a web map draw India's boundary the way the Survey of India does: Jammu and Kashmir, Ladakh (with Gilgit-Baltistan and Aksai Chin) and Arunachal Pradesh inside India, with no stray Line of Actual Control or Line of Control fragments, at every zoom level. No runtime dependencies, Apache-2.0.

npm install bharatmap
import { fixMap } from "bharatmap";
await fixMap(maplibregl, map);   // that is the whole integration for MapLibre

Raster tile basemaps cannot be fixed because the border is part of the image. Full details are in the README.

Let an AI assistant integrate it

That writes instructions for Claude Code, Cursor, Copilot, Windsurf, Gemini CLI or AGENTS.md, depending on what your project uses. Any assistant that can read a URL can follow bharatmap.vkrishna04.me/skill.md, which is always the current version. Claude Code also has a plugin: /plugin marketplace add Life-Experimentalist/bharatmap.

Why a style filter is not enough

Free basemaps (CARTO, OpenFreeMap, MapTiler, Stadia) are built from OpenStreetMap, which draws disputed borders as the lines on the ground. The tile builder merges several disputed borders into one long line, so a filter removes all of it or none of it, and a box big enough to catch the strays also deletes real borders such as Myanmar and Bhutan. bharatmap cuts the geometry inside each vector tile as it loads and draws India's boundary in its place, in the basemap's own line style. See how it works.

Questions

Is the line legally authoritative? No. It follows a published depiction of the Survey of India line. For publication, verify it against the Survey of India itself.

Does it need a server or an API key? No. Only the optional tile proxy needs hosting.

Does it slow the map? Tiles that miss the affected areas are returned untouched, the rest take a few milliseconds.
